## 🌐 تثبيت (PWA)

CalcMaster Ultra هو **تطبيق ويب تقدمي (PWA)** — يمكن تثبيته مباشرة على جهازك:

### 📱 الهاتف (Android / iOS)

1. افتح [الرابط](https://ayad-mounir.github.io/calcmaster-ultra/) في المتصفح (Chrome / Safari)
2. اذهب إلى القائمة ← **"Add to Home Screen"** / **"تثبيت التطبيق"**
3. سيظهر أيقونة على الشاشة الرئيسية — يعمل بشكل شبه كامل بدون إنترنت

### 💻 الكمبيوتر (Desktop)

1. افتح الرابط في Chrome / Edge
2. انقر على أيقونة ➕ فـ شريط العنوان → **"Install"**

> **ملاحظة:** بعد كل تحديث، سيقوم التطبيق بتحديث نفسه تلقائياً. سيظهر إشعار **"🔄 تحديث جديد متوفر — اضغط للتطبيق"** عند توفر نسخة جديدة.

## ⚙️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **Vanilla JS (ES6)** | كل المنطق والمودات مكتوبة بلغة JavaScript خالصة — لا حاجة لأي إطار عمل |
| **CSS Custom Properties** | نظام ثيمات ديناميكي بالكامل عبر متغيرات CSS |
| **Canvas API** | رسم الدوال البيانية في مود الرسم |
| **Web Speech API** | التعرف على الصوت في مود الصوت |
| **Service Worker** | دعم PWA للعمل دون اتصال (Offline-first) |
| **Gold API** | أسعار الذهب والفضة والبلاتين والبلاديوم والنحاس |
| **Oil Price API** | أسعار النفط والبنزين والمازوت والغاز الطبيعي |
| **Frankfurter API** | أسعار صرف العملات الحية |
| **ER API** | سعر صرف الدولار → الدرهم المغربي (MAD) |
