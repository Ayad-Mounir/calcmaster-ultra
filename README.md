# 🚀 CalcMaster Ultra

آلة حاسبة فائقة متعددة الأوضاع مع 9 ميزات متكاملة.

## 🎯 الميزات

| الوضع | الوصف |
|-------|-------|
| **🔢 أساسي** | عمليات حسابية أساسية مع الذاكرة |
| **🔬 علمي** | دوال علمية (sin, cos, tan, log, …) |
| **💻 مبرمج** | HEX/DEC/OCT/BIN + عمليات bitwise |
| **📊 رسم بياني** | رسم الدوال الرياضية (Canvas) |
| **🎂 عمر** | حساب العمر بالسنوات/الشهور/الأسابيع/الأيام/الساعات/الدقائق |
| **✍️ كتابة** | تحويل الأرقام إلى كلمات (عربي/فرنسي/إنجليزي) |
| **💰 عملات** | تحويل العملات بأسعار حية |
| **📏 وحدات** | تحويل الطول/الوزن/الحرارة/المساحة/الحجم/السرعة |
| **🎤 صوت** | إدخال صوتي للأرقام |
